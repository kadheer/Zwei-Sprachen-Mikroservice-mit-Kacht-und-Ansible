## Zwei-Sprachen-Mikroservice-mit-Kacht-und-Ansible
Eine Webapp, die eine Zahl entgegennimmt, sie an einen C++-HTTP-Service Berechnung des Quadrats weiterletet, dann ein Python-Flask-Backend ruft und das Ergebnis auf einer HTML-Seite anzeigt. Alle Komponenten alufen in Docker-Containern, werden auf KAcht deployt und mit Ansible automatisiert installiert.
